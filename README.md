# Security Patrol PWA

Aplikasi patroli security offline-first.

Fitur:
- Petugas & shift
- Tanggal/jam otomatis
- Scan QR dengan BarcodeDetector bila didukung browser
- Input kode titik sebagai fallback
- Kendaraan masuk/pulang
- Riwayat tersimpan di localStorage
- Laporan otomatis
- Bagikan WhatsApp
- Service worker untuk penggunaan offline

## Cara publikasi
Upload file ke hosting HTTPS (misalnya GitHub Pages), lalu masukkan URL aplikasinya ke PWABuilder untuk membuat paket Android. PWABuilder mendukung paket Android berbasis Trusted Web Activity.
